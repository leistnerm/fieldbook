# Task types

`area` answers where a task belongs. `type` answers what kind of work it is.
These are suggested vocabulary, not required fields to debate at capture time.
Use `task` when no more specific type helps. All listed values are valid across
setups; the audience column is guidance, not an access restriction. Add your own
rows here; kit updates preserve this file.

| type | use for | commonly useful to |
|---|---|---|
| task | A concrete next action | Everyone |
| routine | A repeated chore or check | Everyone |
| request | Something someone asked you to do | Everyone |
| appointment | Preparation or follow-up for a dated appointment; calendar remains the event source | Personal |
| errand | A purchase, pickup, return, or local trip | Personal |
| maintenance | Care of a home, vehicle, equipment, or account | Personal |
| admin | Forms, renewals, records, or arrangements | Everyone |
| reading | Reading with an intended outcome | School, work, personal |
| study | Practice, revision, or exam preparation | School, professional learning |
| assignment | Coursework to submit, including labs and essays | School |
| exam | Exam preparation/checklist with the actual exam date recorded | School |
| research | An investigation with a question and next action | Everyone |
| delivery | Building or shipping a defined result | Individual contributor |
| bug | Investigating or fixing a defect | Individual contributor |
| incident | Responding to or following up an interruption | Work |
| review | Reviewing a document, design, code, or submitted work | Everyone |
| planning | Defining scope, sequencing, or coordinating work | Work, school |
| mentoring | A concrete coaching or mentoring action | Both work roles |
| management | Staffing, delegation, or people-management follow-up | People manager |
| training | A learning activity or required course | Everyone |
| poll | A survey or feedback form | Everyone |
| corporate | Organization-specific compliance or administration; retained for older vaults | Work |

`review` is a task type; a saved performance review is a note tagged `review`.
A research task is an action; a `Research/` note holds the investigation evidence.
Recurring tasks use TaskNotes recurrence rather than making a new type per habit.
