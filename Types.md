# Types

Allowed values for a task's `type` field. Add a line here to add a type.

| type       | use for                                                  |
|------------|----------------------------------------------------------|
| task       | project work I'm doing                                   |
| request    | someone asked me for something (fill `requester`)        |
| management | team/people management: hiring, reviews, staffing, 1:1 follow-ups |
| training   | required or chosen training                              |
| poll       | surveys, polls, feedback forms                           |
| corporate  | other org requirements: compliance, admin, attestations  |
| routine    | recurring chores (weekly status update, etc.)            |
