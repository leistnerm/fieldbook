---
name: list-management
description: Create and maintain lightweight shopping, packing, reading, materials, project or other checklists without making every checkbox a task.
---

Use Templates/List.md in Lists/. Lists work in personal, work or school. Resolve
which list is intended and check duplicates before creating one. Ordinary entries
remain checkboxes; preserve quantity, brand, dietary constraints and other details
only when supplied. Buying or checking off an item is not an accomplishment by default.
A wishlist is not authorization to purchase. A list can link to a project or person.
Promote an entry to a task only when the user requests it or accepts a suggestion
because it needs a deadline, owner or follow-up. Replace that checkbox with the
task link so there are not two competing completion states. Reusable packing or
maintenance checklists are templates for the user's next use, not automatically
reset histories. Never silently uncheck completed entries. Use notebook_write for
requested changes; no purchasing, account access or invented prices.
