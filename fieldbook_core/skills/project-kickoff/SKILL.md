---
name: project-kickoff
description: Turn a personal goal, work deliverable, or school project into a scoped project and concrete next actions.
---

Use the user's outcome, deadline, constraints and available context. Distinguish a
project (an outcome requiring several actions), an ongoing course, and a single
task. Start with the outcome, useful scope and first actionable tasks. Add
milestones, dependencies, costs, stakeholders and risks only when the scale or
request warrants them; a small personal goal needs no corporate project process.
Consequential unknowns stay explicit gaps, not a checklist of required answers.
Use Templates/Project.md by default, with root Projects/ and Tasks/. Course.md is
an explicit school course choice through study-planning, never implied by area.
Inherit area onto tasks. Show the intended notes when creating a batch;
write after the user approves the concrete plan or explicitly requests that batch.
Do not turn every milestone into a separate project. Link to the most specific
project and check for existing notes before creating new ones.

Offer a concrete next action, confirmed owner, decision/check-in date and dependency
for the requested outcome. For a work specialization, choose only useful details:
sales/customer next steps and renewals; procurement comparison and notice dates;
cybersecurity/IT remediation and incident learning; executive delegated commitments;
teaching lesson/assessment preparation. Ordinary Project/Task/Decision/Note records
are sufficient. A role label does not justify importing unrelated HR or personal
context, assigning work, changing systems, or inventing commitments.

## Optional goals

Use /goal and Templates/Note - Goal.md when an outcome needs its own lightweight record.
Goals work in every setup and stay in Notes/ with note and goal tags. Record the
user's desired outcome, supplied success measure, optional target/check-in, linked
projects and cited evidence. A goal is not automatically a project or task. Progress
claims need evidence; assignment and links alone do not establish achievement.
