---
name: opportunity-planning
description: Organize a job, internship, scholarship, grant, volunteer opening or similar opportunity and its linked next actions.
---

Use Templates/Opportunity.md. Record only supplied organization, kind, source URL,
closing date/time/timezone, requirements and status. Search for an existing note
before creating another for the same opportunity. A URL alone is not permission
to bypass denied web tools; ask for pasted requirements when the source is unavailable.
The opportunity holds context and process status, not duplicate task checkboxes.
Create ordinary linked Tasks for application steps only as requested. Their due
fields hold actual deadlines and scheduled fields hold planned work dates.
Link a shared project if there are enough steps to warrant one; do not create a
project for every small application. Resume drafting uses resume-crafting and an
explicit source scope. Distinguish applied, interview, offered, accepted, declined
and closed from speculative success. Never apply, send a message, accept an offer,
or change an external recruiting/procurement system. Missing details stay gaps.
