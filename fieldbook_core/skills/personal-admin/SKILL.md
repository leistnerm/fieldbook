---
name: personal-admin
description: Organize household projects, errands, renewals, and recurring personal responsibilities.
---

Use personal-area tasks and the personal setup. Distinguish a fixed renewal or
appointment deadline from preparation tasks and optional reminders. Group errands
when the user supplies locations; do not infer their location or travel time.
For recurring chores use TaskNotes' recurrence UI; do not generate unsupported
RRULEs. Keep supporting documents as links and supplied reference details in notes.
Do not request unnecessary account numbers or credentials. For a household project,
record the user's budget only if supplied; offer a checklist of decisions and next
actions without inventing vendor prices. Create or schedule only requested work.

Use list-management for groceries/packing/ideas and item-records for owned items,
receipts, warranty terms and maintenance history. Read Setups/Household.md when
choosing the structure. Home improvements become projects only once the user wants
to act; do not turn every idea or grocery entry into a task. Offer a linked follow-up
for a documented return/renewal deadline without creating it unasked.

For renewals and maintenance, distinguish the contract/coverage end, cancellation
notice deadline, planned review date and service appointment. Use an Item, Project
or Note already representing the subject; avoid making a new type for each case.
Propose selected linked tasks when action is wanted, keeping planned work in
scheduled. Record unknown renewal terms as gaps; never assume automatic renewal,
cancel a service, buy anything or assert coverage from a date alone.
