Person: $ARGUMENTS. Match the person note and clarify ambiguous names. Follow
AGENTS.md scope rules. A 1:1 can be with a friend, classmate, instructor, peer,
customer, manager or report; no work setup or report relationship is required.
Get today's local date with notebook_today when needed.

Gather shared context relevant to this conversation:
- Recent notes and the last 3 meetings with the person, including open follow-ups,
  decisions to revisit and commitments from the last 60 days.
- Linked projects/tasks relevant to the request, with blockers or dates when useful.
  An assigned task is not proof of achievement or a performance problem.
- Topics or goals the user explicitly wants to discuss, already recorded in the
  selected context. Do not search private reviews, HR details or birthdays by default.

Suggest a short agenda led by the purpose, questions and agreed follow-ups. Skip
empty categories. Do not turn a catch-up into a performance review or add goals,
feedback or employment fields to the person note. If manager coaching is explicitly
requested, use manager-coaching and its role/report checks; otherwise stay general.
Don't edit files. Offer to create today's meeting from Templates/Meeting.md in
Meetings/YYYY/YYYY-MM/, named YYYY-MM-DD 1on1 <Person>, with attendees linking to
the person, the selected area/projects and the agenda. Create only if requested
or accepted; if that note exists, offer to use it instead of duplicating it.
