Input: $ARGUMENTS
Load the people-context skill. If skill discovery is unavailable, use notebook_read on
fieldbook_core/skills/people-context/SKILL.md and follow it. Follow AGENTS.md and use notebook tools.
For creation default to Templates/Person.md. A requested professional contact uses
Templates/Person - Professional contact.md; an explicitly identified direct report uses
Templates/Person - Direct report.md when work + people-manager is enabled. In other setups,
use Person with the supplied relationship report; do not enable management implicitly.
Listing or viewing people does not create records.
