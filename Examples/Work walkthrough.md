# Work walkthrough

This example is fictional. It illustrates a common cross-team improvement project;
it does not describe a person, employer or actual result.

1. Create a Person record with `relationship: self` and agreed goals.
2. Use `/kickoff` for a project such as improving a shared request-intake process.
3. Record decisions, tasks and meetings. Log your own contribution separately from
   the team's outcome. Optional tracker connections read source records only.
4. Capture an accomplishment when useful, linking original evidence.
5. Use `/evidence me mid-year`, then `/review me mid-year` to prepare a draft.

## Illustrative review excerpt

> **Outcome:** I drafted a request checklist and coordinated feedback from two
> teams. The team piloted the checklist and identified unclear handoff steps.
> **Evidence to supply:** links to the draft, pilot notes and dated feedback.
> **Lesson:** agree on ownership before the next pilot.
> **Next priority:** propose a shared handoff guide and an agreed way to measure
> whether it reduces clarification requests.

Do not copy these claims into an actual review. Replace them with supported facts
from the selected period. Do not invent savings, ratings or performance metrics.
The optional review template contains adaptable prompts for outcomes, collaboration,
challenges, learning, priorities and support needs.
