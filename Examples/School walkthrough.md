# School walkthrough

Create History - Fall 2026 from Course, with term Fall 2026. Supply syllabus text to /course. Approve an assignment task linked to the course with its deadline. /study proposes reading, outline and revision work days; /term-close later reviews unfinished work before closing the course.

This is a walkthrough, not a live task. Use fictional data for your first test.

## Optional Canvas deadline review

After school + Canvas are configured, try:

```text
/canvas-sync school coursework for course 12345; planner context from 2026-10-01 to 2026-10-31; offer missing records
```

A graded quiz appearing in assignments and Planner becomes one proposed record.
A discussion with an initial post due Tuesday and replies due Friday keeps both
stage deadlines. A reading page's to-do date stays a reminder, and a quiz closing
time stays an availability limit. Review conflicts before saving. A single task
has one due field; request separate stage tasks if both discussion dates must
appear on task dashboards. Repeating the sync searches saved source identities and
aliases first. See [[Canvas LMS]] for supported sources and coverage limits.
